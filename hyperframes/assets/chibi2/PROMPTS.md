# 質問役キャラ 画像生成プロンプト（対談チャンネル用）

聖さんchibiと**同じ絵柄で並ぶ**ためのプロンプト。
ChatGPT画像（GPT Image）またはManusで生成する。

## ⭐最重要：やり方
1. ChatGPTの画像生成を開く
2. **聖さんのchibi画像を1枚アップロードして「参照画像」にする**
   （例: `sns-automation/hyperframes/assets/chibi/poses/explaining.png`）
3. 下のプロンプトを貼る（「参照画像と同じ画風で」と最初に書いてある）
4. 生成された画像を、下の「保存ファイル名」で `assets/chibi2/` に保存

これで画風・線・塗り・頭身が聖さんと揃う。

---

## 生成する画像（最低4枚）

| 保存ファイル名 | 用途 |
|---|---|
| `mouth_closed.png` | 口を閉じた通常（聞いてる） |
| `mouth_open.png` | 口を開けた状態（話してる・口パク用。※body pose は mouth_closed と完全に同じで口だけ違う） |
| `poses/curious.png` | 首をかしげて質問する（え、それって？） |
| `poses/surprised.png` | 驚き・なるほど！（両手を軽く広げる） |

---

## プロンプト①：mouth_closed.png（基準ポーズ・まずこれを作る）

```
参照画像と完全に同じ画風・同じ塗り・同じ線・同じ頭身（低めのちびキャラ）で、
別人の女性キャラクターを1体描いてください。

【キャラ】
20代後半の日本人女性。やわらかく親しみやすい雰囲気の「聞き手・アシスタント」。
ミディアムのやわらかい茶色の髪（肩くらい、毛先ゆるめ）。大きく澄んだ瞳、
細めのやさしい眉、ほんのり頬の赤み。清潔感のある表情、口は閉じて軽くほほえむ。

【服装】
きれいめカジュアル。クリーム色〜ベージュのゆったりニット、またはやわらかい白ブラウス。
下は細身のベージュのパンツ。シンプルで上品。派手すぎない。

【ポーズ・構図】
全身・直立・正面やや斜め。両手は体の横に自然に下ろす（何も持たない）。
背景は完全に透過（PNG・アルファ）。キャラだけ。影は落とさない。
縦長の高解像度。人物は画面中央に全身が収まる。
```

保存: `assets/chibi2/mouth_closed.png`

---

## プロンプト②：mouth_open.png（①ができてから）

①で作った画像を**参照画像に追加**して、こう指示する：

```
この女性キャラを、体・髪・服・ポーズ・角度は完全に同じまま、
口だけを開けて「話している」表情にしてください（口を開けて発話中）。
それ以外は1ピクセルも変えないでください。背景は透過のまま。
```

保存: `assets/chibi2/mouth_open.png`
※これで口パク（閉じ↔開き）がきれいに切り替わる。

## プロンプト③：poses/curious.png

```
参照画像と同じ画風・同じ女性キャラで、
「首をかしげて質問する」ポーズ。片手を軽くあごに添え、少し首をかしげ、
目を大きくして「え、それってどういうこと？」という好奇心の表情。口は少し開ける。
全身・正面やや斜め・背景透過（PNG）・影なし・縦長高解像度。
```

保存: `assets/chibi2/poses/curious.png`
