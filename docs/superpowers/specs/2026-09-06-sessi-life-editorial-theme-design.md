# sessi.life リール editorial テーマ 設計書

作成日: 2026-09-06
対象: WF4（Instagram リール自動投稿）のうち @sessi.life 1アカウントのみ

## 背景

@tatsu.insta_ai（たつ｜インスタ特化のAI活用術・41投稿・フォロワー2,678人）の
見た目を再現したい、という要望が出発点。仕組みの面では sns-automation が
すでに同等以上（GitHub Actions で6アカウントに毎日自動投稿、Remotion レンダリング、
VOICEVOX TTS、Pexels/Pixabay B-roll）を持っているため、不足しているのは
レンダラーに渡すデザイン定義だけ、と判断した。

追加の有料ツールは不要。Playfair Display は Google Fonts、写真は Pexels と
Pixabay の無料枠、音声は VOICEVOX、台本は Groq で、いずれも現行の支払い範囲に収まる。

## tatsu.insta_ai の観察（2026-09-06 実見）

41投稿すべてがリール。表紙の構成が1投稿も崩れていない。

1. 全面の実写 B-roll を、素材が何であれ暖色（ベージュ〜テラコッタ）に色調統一している
2. 英語のセリフ体イタリック2行。1行目が白、2行目が淡い金
3. 細い白線の内枠と、上から中央に落ちる縦線1本
4. サーモン／テラコッタのベタ箱に日本語3行。情報を持つのはここだけ
5. 箱の下に小さな星マーク1つ。それ以外の飾りは何も置かない。キャラクターも置いていない

結論として、高級感は毎回凝ることからではなく、一度決めた型を動かさないことと、
それ以外を何も置かないことから出ている。したがって本設計でも、型が受け取る引数を
最小限に絞り、位置・色・余白を引数にしない。

## 現行 WF4 の構造（実装確認済み）

`scripts/generate-reel.js` の実装は次の通り。設計はこの構造を前提にする。

- レンダリングするコンポジションは `MyVideo`（1080×1920・`remotion/src/MyVideo.tsx`）。
  `RichSlideVideo.tsx` は YouTube 用の 1920×1080 で、WF4 とは無関係
- 1本 = 9シーン（`SCENE_COUNT = 9`）
- `DIAGRAM_SLOTS = [0, 2, 4, 6, 8]` が線画アイコン図解、`CUT_SLOTS = [1, 3, 5, 7]` が4秒の実写カット
- `title` という種別のシーンは存在しない。グリッドに出る表紙は0番の図解シーン
- 字幕バーは全シーンに出る（`CaptionBar`・地色 NAVY・left 48 / bottom 90 / width 984 / minHeight 130）
- B-roll は9シーン全部に入る。図解シーンでは3pxぼかした上に
  `rgba(255,255,255,0.7)` の白ベールをかぶせて「動く紙」にしている。実写カットは素のまま
- B-roll の取得は Pexels を引き、空振りしたときだけ Pixabay を引く（`generate-reel.js` 309行目）
- ちびキャラは全シーンの上に乗る独立したオーバーレイ。`data/wf4_accounts.json` の
  `chibi: true` で有効になる。**sessi_life には付いていない**（他5アカウントには付いている）

## 適用範囲

- 対象は @sessi.life のみ。satoshi_mindset / satoshi_mind_coaching /
  ise_sato_kosodate / ise_kenkou_otaku / tabi_life_design の5アカウントは変更しない
- @ko_gi_omoti（WF3）と YouTube（WF6）も対象外

## デザイン仕様

### 方針

2026-07-25 に確定した線画アイコン図解（flow3 / iconsteps / reject / stairs /
process / databadge）のレイアウトは1つも変更しない。変更するのは
「表紙」と「4秒の実写カット」の2つの型で、どちらもレイアウト構造ごと差し替える。
図解シーンは配色のみ暖色側に寄せる。これは色替えが目的ではなく、
再生中に白背景と暖色の実写が交互に来て色が割れるのを防ぐための従属的な調整。

表紙は0番スロットに新しい型を差し込む。editorial のとき
`DIAGRAM_SLOTS` は `[2, 4, 6, 8]` になり、0番は cover 型になる。
シーン総数は9のまま変わらない。

### トークン

新規ファイル `remotion/src/editorialTheme.ts` に集約する。デザイン変更はここ1か所。

写真のグレーディング（どの素材が来ても同じ色に着地させる）

| 用途 | 値 |
|---|---|
| 映像フィルタ | `saturate(0.85) contrast(0.95) sepia(0.18)` |
| 全面の暖色レイヤー | `rgba(198,161,132,0.34)` |
| 上部の落とし | `rgba(90,66,50,0.42)` を 0% → 38% |
| 下部の落とし | `rgba(60,42,32,0.30)` を 78% → 100% |

配色

| 名前 | 値 | 用途 |
|---|---|---|
| TERRA | `#c9755c` | 日本語コピーのベタ箱・実写カットの横帯 |
| GOLD | `#f0dd8e` | 英語2行目・図解のマーカー |
| LINE | `rgba(255,255,255,0.85)` | 内枠と縦線（2px） |
| CREAM | `#f6efe6` | 図解シーンの地色（現行 `#ffffff`） |
| CREAM_VEIL | `rgba(246,239,230,0.72)` | 図解シーンの B-roll ベール（現行 `rgba(255,255,255,0.7)`） |
| WARM_INK | `#3a2f28` | 図解の線・文字・字幕バー（現行 `#1a1a1a` / `#2b2b2b` / `#16202e`） |
| WARM_RED | `#b4553c` | 図解の赤（現行 `#d92b2b`） |
| WARM_RED_TEXT | `#a84a34` | 本文中の強調赤（現行 `#c62222`） |
| GOLD_SOLID | `#edd06a` | 暗い背景用のベタ塗り（現行 `#ffe500`） |

書体

- 英語: Playfair Display Italic（`@remotion/google-fonts/PlayfairDisplay`）
- 日本語: Zen Maru Gothic（現行のまま変更なし）

### 型①: カバー（0番スロット・新規の `cover` 型）

キャンバス 1080×1920。最小尺4.5秒（音声がそれより長ければ音声に合わせる）。

- 全面 B-roll。0秒から終端まで scale 1.00 → 1.06 のゆっくりズーム
- 縦線: x=540、y=0→540、幅2px、LINE
- 内枠: left 122 / right 122 / top 540 / bottom 346、border 2px LINE
- 英語1行目: y=670、中央揃え、104px、白、Playfair Italic 500
- 英語2行目: y=806、中央揃え、112px、GOLD、Playfair Italic 600
- 日本語箱: left 223 / right 223 / top 1066、padding 54px 36px、背景 TERRA、
  Zen Maru Gothic 900 54px / line-height 1.62、白、中央揃え、最大3行。
  4行以上が渡された場合は3行目までで切り捨てる（縮小もはみ出しもさせない）
- 星: 箱の下 56px、白、68px の ✤
- 入り: 英語が上から18px、箱が下から24px。両者を6フレームずらす

型が受け取る引数は次の3つだけ。位置・色・余白・フォントサイズは引数にしない。

- 背景動画のパス
- 英語2行（文字列2要素）
- 日本語3行（改行込みの文字列）

### 型②: 実写カット（`cut` 型の editorial 版）

カバーと同じ型を使い回すと再生中が単調になるため、構造を変える。
カバーが「中央に箱」なのに対し、こちらは「下3分の1に横帯」。

- 全面 B-roll、グレーディングはカバーと同一
- 上部 y=150 に英語1行、Playfair Italic 44px、letter-spacing 0.18em、
  白 opacity 0.9、中央揃え
- 下部の横帯: top 1320、height 300、TERRA のベタ
- 帯の上に日本語の一言: Zen Maru Gothic 900 76px、白、中央揃え、最大2行。
  3行以上が渡された場合は2行目までで切り捨てる
- 帯の乗りをよくするため、1180 → 1320 に `rgba(40,28,22,0.35)` を薄く敷く
- 現行の上下の濃いグラデーション（`rgba(10,14,20,0.86)` ほか）は使わない
- 帯を 1620 で終わらせるのは、リール再生時に画面下部およそ350pxが
  キャプションと UI に覆われるため。帯をそれより上に収めて隠れないようにする

### 図解シーンの調整

レイアウトは一切変更しない。`MyVideo.tsx` の色定数をテーマ経由で引くようにし、
editorial のときだけ上のトークン表の右列に差し替える。
差し替え対象は PAPER / INK / DARK / RED / RED_TEXT / NAVY / YELLOW_MARK /
YELLOW_SOLID の8つ。

加えて、B-roll にかぶせている白ベールを CREAM_VEIL に差し替える。
ぼかし3pxはそのまま。これで図解シーンの下でも同じ暖色の B-roll が生き、
表紙・実写カットと色が揃う。

### キャラクター

sessi.life には出さない。理由は3つ。

1. tatsu.insta_ai はキャラクターを一切置いていない。余白そのものが高級感の正体であり、
   右下にワイプを立てるとそれを打ち消す
2. sessi_life には元から `chibi: true` が付いておらず、今も出ていない。
   つまり本設計で何かを取り上げるわけではない
3. 使える素材は聖さんのちびキャラ（男性・8ポーズ）と対談用のあかり（2ポーズのみ）だけで、
   せっしー（黒髪ボブの30代女性）のちび画像が存在しない

なお ChibiOverlay は全シーンの上に乗る独立レイヤーなので、後から出したくなった場合でも
新しい2つの型と競合はしない。ただし既定位置（下から300px・高さ330px）は
実写カットのテラコッタ帯（1320〜1620）と完全に重なるため、出す場合は帯かキャラの
どちらかを動かす必要がある。

## 実装

### ファイル構成

| ファイル | 種別 | 内容 |
|---|---|---|
| `remotion/src/editorialTheme.ts` | 新規 | トークン定義。デザイン変更はここだけ |
| `remotion/src/EditorialScenes.tsx` | 新規 | `EditorialCover` と `EditorialCut` の2コンポーネント |
| `remotion/src/MyVideo.tsx` | 変更 | `Scene` に `theme?: "editorial"` と `cover` 型、`titleEn` を追加。`cover` と `cut` の分岐で新旧を出し分け。色定数と `CaptionBar` の地色とベールをテーマから引く |
| `scripts/generate-reel.js` | 変更 | editorial のときスロット配分を変更。Groq プロンプトに0番の cover 用出力と `title_en` を追加。フォールバックを実装。B-roll 取得を Pexels と Pixabay の合流に変更 |
| `data/wf4_accounts.json` | 変更 | sessi_life に `"theme": "editorial"` を1行追加 |

### 切り替えとロールバック

`data/wf4_accounts.json` の sessi_life に `"theme": "editorial"` があるときだけ
新しい型が使われる。他5アカウントは無指定なので現行のまま動く。
やめる場合はこの1行を消す。コードは残るが選ばれない。

### スロット配分

- 既定: `DIAGRAM_SLOTS = [0, 2, 4, 6, 8]` / `CUT_SLOTS = [1, 3, 5, 7]`
- editorial: スロット0が `cover`、`DIAGRAM_SLOTS = [2, 4, 6, 8]`、`CUT_SLOTS` は変更なし
- シーン総数は9のまま。`assignDiagramLayouts()` が返す図解レイアウトは5個から4個になる

### 英語タイトルの生成

台本を書いている Groq に、2要素の配列 `title_en` を同時に出させる。
各要素は英字とスペースのみ、12文字以内。

AI が構造を外したときのために `buildFallbackTitleEn()` を実装する。
台本のテーマ語から固定表を引く。

- スキンケア → `["Daily Skin", "Care Routine"]`
- 乾燥 → `["Winter Skin", "Dry Season"]`
- 日焼け止め → `["Morning Light", "Sun Care"]`
- 表にない場合 → `["Beauty Notes", "Today's Tip"]`

12文字を超えた要素は切り詰める。結果として `title_en` は必ず2要素になる。

### B-roll の取得

現行は Pexels を引き、空振りしたときだけ Pixabay を引くフォールバック方式
（`generate-reel.js` 309行目）。これを両方を毎回引いて候補を合流させる方式に変える。

- Pexels と Pixabay の両方を同じキーワードで検索し、結果を1つの候補配列にまとめる
- 既存のかぶり除外（`data/wf4_used_ids/*.json` を全アカウント横断で読む）と
  6秒未満の足切りは、合流後の配列にそのまま適用する
- 合流後の候補からランダムに選ぶ。どちらか一方が失敗しても、もう一方の候補で成立する
- 記録は現行どおり自アカウントの台帳にのみ書く

素材の母数が増えるため、同じ色に統一したときの見え方が安定し、
使い回しも減る。API キーは両方とも取得済み（`PEXELS_API_KEY` / `PIXABAY_API_KEY`）。

## 検証

本番投稿の前に、次の順で確認する。

1. `npx remotion still` でカバー1枚と実写カット1枚と図解1枚を書き出す
2. tatsu.insta_ai のグリッドと並べて見比べ、色の濃さ・余白・文字サイズのズレを詰める
3. 聖さんの承認が出るまで本番投稿しない
4. 承認後、sessi_life 1本だけ実投稿して実機のグリッドで確認する
5. 他5アカウントを1本ずつレンダリングし、見た目が変わっていないことを確認する

高級感は数値では判定できないため、ステップ2で必ず目視の突き合わせを行う。
一発で合わない前提で、色の濃さと余白から先に調整する。

## コスト

追加ゼロ円。Playfair Display は Google Fonts のため
`@remotion/google-fonts` でレンダラーに同梱できる。写真は Pexels と Pixabay の
無料枠、音声は VOICEVOX のローカルエンジン、台本は Groq の無料枠で、
いずれも現行の支払い範囲に収まる。Pixabay を毎回引くようになるが無料枠の範囲内。

## やらないこと

- 他5アカウントへの適用。sessi.life の結果を見てから別途判断する
- 図解レイアウトの新規追加・削除。既存6型はそのまま残す
- せっしーのちびキャラ画像の作成。本設計ではキャラを出さないため不要
- キャプション文面の型の導入。tatsu.insta_ai は固定の型を使っているが、これは別件
- プロフィールのリンク導線と自作ツールサイト。これも別件
